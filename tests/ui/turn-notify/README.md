# turn-notify

Plan 0.4.0 #33. Un turno PLAN termina en otra conversación de Normal mientras
miras otra: el aviso dice «El plan de «X» está listo para revisar» con
«Revisar plan», la barra lateral marca la conversación, la campana la nombra
en «Conversaciones» y «Revisar plan» abre la tarjeta del plan.

```bash
npm run ui:e2e -- turn-notify
```
